# guild/starter docs

> For developers creating, running and configuring a Guild app from guild/starter.

How a Guild app works, such as sign-in, permissions and pages, is in
[guild/framework's docs](https://github.com/nathanskky/guild-framework/blob/main/docs/index.md). These
pages cover creating and running an app.

## Start

- [Create an app](start/create-an-app.md) — read when starting a new app from guild/starter.
- [Run locally](start/run-locally.md) — read when starting, restarting or reaching your app in Docker, or running its tests.
- guild/dev-tools' [Turn persona sign-in on and off](https://github.com/nathanskky/guild-dev-tools/blob/main/docs/start/turn-persona-sign-in-on-and-off.md) — read when switching between personas and IU Login, or changing the personas.

## Guides

- [Manage secrets](guides/manage-secrets.md) — read when setting up IU Login and Grouper credentials, or adding a setting.
- [Remove the example code](guides/remove-the-example-code.md) — read when replacing the example page with your own.
- [Turn off authorization](guides/turn-off-authorization.md) — read when your app needs sign-in but no permissions.
- [Sign in with Apache CAS](guides/sign-in-with-apache-cas.md) — read when your app uses Apache `mod_auth_cas` instead of IU Login.
